# 阶段 5：SoC 集成与 FPGA 上板

## 目标

把 CPU 从“仿真中的核”推进为“能在板上跑程序的最小系统”。

## 建议任务

1. 设计最小 SoC 顶层。
2. 集成 ROM、RAM、UART、Timer。
3. 定义统一地址映射。
4. 让 CPU 的握手式接口接入 SoC 侧存储与外设。
5. 准备 Vivado 工程、约束文件和板级时钟复位。
6. 建立最小可观测调试路径，例如串口输出或 LED 状态。

## 设计关注点

1. 慢速外设访问如何反馈到 CPU stall。
2. 外设地址映射和主存地址映射如何统一。
3. 板级 bring-up 时如何快速判断是 CPU、SoC 还是外设问题。

## 阶段产出

1. SoC 顶层 RTL。
2. 地址映射文档。
3. FPGA 工程与约束文件。
4. 板级 bring-up 记录。

## 验证要求

1. SoC 级程序可在仿真中跑通。
2. FPGA 上能执行最小程序并产生可观察输出。
3. 慢速外设不会破坏 CPU 流水线控制。

## 退出条件

1. 最小系统可在板上运行。
2. UART、Timer 等关键外设可用。
3. 可以进入系统级验证和 RTOS 尝试阶段。
