# 阶段 1：五级流水线 CPU 主体

## 目标

在没有完整 Hazard Unit 的前提下，先让 CPU 主体跑通无冲突的基础程序。

## 关键约束

1. 不追求本阶段解决所有冒险问题。
2. 优先保证主数据通路和控制信号跨级传递正确。
3. 所有存储访问都走阶段 0 定义好的握手接口。

## 建议任务

1. 实现 IF、ID、EX、MEM、WB 五级主体结构。
2. 接通 PC、寄存器堆、ALU、立即数生成器和基础控制器。
3. 添加阶段间流水线寄存器。
4. 实现 `EX` 阶段 branch 判定与跳转目标生成。
5. 支持无复杂相关程序的顺序执行。

## 本阶段优先支持

1. 基础整数运算。
2. Load/Store。
3. `jal`、`jalr`。
4. 基础 branch。

## 阶段产出

1. CPU 顶层 RTL 初版。
2. 基础模块 RTL。
3. 简单 smoke test 程序。
4. 首轮波形记录。

## 验证要求

1. 运行不含复杂数据相关的基础程序。
2. 检查寄存器写回结果和 PC 变化。
3. 验证 `EX` 阶段分支重定向是否符合预期。

## 退出条件

1. CPU 能稳定运行简单程序。
2. 主数据通路和跨级控制信号没有明显错位。
3. 可以进入冒险处理收敛阶段。
