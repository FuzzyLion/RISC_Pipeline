# 阶段 4：CSR、异常与中断

## 目标

建立最小 Machine Mode 闭环，为系统软件和后续 RTOS 支持打基础。

## 建议任务

1. 固定第一版最小 CSR 列表。
2. 实现异常陷入流程。
3. 实现异常返回流程。
4. 实现 `mstatus`、`mtvec`、`mepc`、`mcause` 等必要 CSR。
5. 引入至少一种中断源，建议优先定时器中断。
6. 完成异常与中断下的流水线清空和跳转重定向。

## 设计关注点

1. 异常和中断优先级如何定义。
2. Trap 发生时流水线中哪些级需要清空。
3. CSR 写入、PC 重定向与冒险控制如何协调。

## 阶段产出

1. CSR 模块。
2. trap/return 设计说明。
3. 异常与中断测试程序。
4. 关键波形与行为记录。

## 验证要求

1. 异常进入后 CSR 写入正确。
2. 中断进入与返回路径正确。
3. 异常或中断发生时，流水线状态一致且可解释。

## 退出条件

1. 最小特权态闭环已经建立。
2. Timer 中断等关键前置能力可用。
3. 可以进入 SoC 集成阶段。
